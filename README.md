# TrailQuest GitHub Pages Redirect

This folder is ready to use as the GitHub Pages source for TrailQuest.

## Setup

1. Open `index.html`.
2. Replace `PASTE_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE` with the current Google Apps Script web app `/exec` URL.
3. Push this `docs` folder to GitHub.
4. In the GitHub repository, go to Settings -> Pages.
5. Set the source to the `docs` folder on the main branch.

After GitHub Pages publishes, visitors will briefly see the TrailQuest redirect screen and then be sent to the Apps Script app. The button remains available as a manual fallback.
